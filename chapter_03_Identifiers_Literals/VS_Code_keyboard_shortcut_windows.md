## Tips and Tricks

### Multi-Cursor Editing
- **Alt + Click**: Place multiple cursors
- **Ctrl + Alt + Up/Down Arrow**: Add cursor above/below
- **Ctrl + D**: Select next occurrence
- **Ctrl + U**: Undo last cursor operation

### Quick Actions
- **Ctrl + .**: Quick actions/quick fixes
- **Ctrl + Shift + P**: Command palette for any action
- **F1**: Show command palette

### Productivity
- **Ctrl + K, Ctrl + C**: Add line comment
- **Ctrl + K, Ctrl + U**: Remove line comment
- **Shift + Alt + F**: Format entire document
- **Ctrl + K, Ctrl + F**: Format selected text

### Customization
- **Ctrl + K, Ctrl + S**: Open keyboard shortcuts
- **Ctrl + ,**: Open settings
- **Ctrl + K, Ctrl + T**: Change color theme

## Common Workflows

### Quick File Navigation
```
Ctrl + P → Type filename → Enter
```

### Find and Replace
```
Ctrl + H → Type search term → Tab → Type replacement → Replace All
```

### Code Formatting
```
Shift + Alt + F (entire file)
Ctrl + K, Ctrl + F (selection)
```

### Split Editing
```
Ctrl + \ (split editor)
Ctrl + 1/2/3 (focus group 1/2/3)
Ctrl + K, Left/Right Arrow (focus left/right group)
```

### Debug and Run
```
F5 (start debug)
F10 (step over)
F11 (step into)
Shift + F11 (step out)
```
