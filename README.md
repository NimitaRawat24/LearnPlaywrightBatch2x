# Learn Playwright - Batch 2x

A comprehensive learning repository for mastering Playwright browser automation testing, JavaScript fundamentals, and web development concepts. This repository is part of the Nagarro Learning Initiative and contains structured lessons, examples, and best practices.

## 📚 Repository Overview

This repository is designed as a progressive learning path, starting from JavaScript basics and gradually advancing to Playwright automation testing concepts. Each chapter contains practical examples, detailed explanations, and hands-on exercises.

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v14 or higher)
- **Visual Studio Code** (or any code editor)
- **Git** (for version control)
- **Windows OS** (repository examples are Windows-specific)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/NimitaRawat24/LearnPlaywrightBatch2x.git
   cd LearnPlaywrightBatch2x
   ```

2. **Verify Node.js installation**:
   ```bash
   node --version
   npm --version
   ```

3. **Run a file**:
   ```bash
   node chapter_01_Basics/01_Basics.js
   node chapter_03_Identifiers_Literals/03_Identifier_Rules.js
   node chapter_03_Identifiers_Literals/04_Naming_Conventions.js
   ```

## 🐛 Troubleshooting

### Issue: Node.js is not recognized

**Solution**: 
- Install Node.js from https://nodejs.org/
- Restart your terminal/VS Code
- Verify installation: `node --version`

### Issue: Files won't run

**Solution**:
- Ensure you're in the correct directory
- Check file path: `node ./chapter_01_Basics/01_Basics.js`
- Verify Node.js installation

### Issue: VS Code extensions not working

**Solution**:
- Check VS Code keyboard shortcuts: `Ctrl + K, Ctrl + S`
- Verify extensions are installed and enabled
- Restart VS Code
